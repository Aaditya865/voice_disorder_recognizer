# Demo audio

These are real VOICED development recordings. Healthy and laryngitis examples use the lowest development record ID in their group. The pathological example reuses voice003, the already supplied unseen-to-training demonstration. File names describe dataset labels, not guaranteed predictions. Examples are illustrative, not a performance estimate. All clips are sustained /a/, central three seconds, mono 8 kHz. Double-precision WAV preserves the original feature input.

The website recognizes the audio fingerprint and automatically uses speaker-held-out validation models. The speaker is excluded from fitting and early stopping; model-setting selection still used development validation. Do not convert these files to MP3 for an unseen-speaker claim: compression changes the fingerprint and signal.

Source: VOICED 1.0.0, https://physionet.org/content/voiced/1.0.0/ . Open Data Commons Attribution License v1.0. See REFERENCES.txt.
