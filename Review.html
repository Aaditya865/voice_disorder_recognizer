01 / EXPERIMENT

From recording to prediction

Audit + participant split→Central 3 s /a/→MFCC + voice quality→GMM / DNN→Validation

Statistical baseline

Class-conditional diagonal GMMs on pooled MFCCs, with optional voice-quality measurements. Equal class priors; 1, 2 and 4 components tested.

Temporal neural model

Two convolution layers, global-average pooling and a compact classifier, with an optional voice-quality branch. Training-only class weights and early stopping.

Selected settings: GMM: GMM combined 1; DNN: DNN combined 0.4. This compares complete pipelines with different pooling, not architecture alone.

TRAINING STABILITY

How much does a training run matter?

DNN predictions change for some participants across training seeds, so a single-run result is fragile. The selected one-component GMM is effectively deterministic on fixed data; its zero seed spread is expected and does not imply robust generalization. The same development folds selected the configurations, so selection bias remains. Seed standard deviations are descriptive, not confidence intervals. No best seed is selected and no demonstration model is replaced.

03 / VALIDITY

What the experiment can and cannot establish

  • Participant and duplicate hashes are disjoint across development and test partitions.
  • Record IDs are participant proxies based on the dataset documentation; cross-session identity cannot be independently reverified.
  • Scaling, imputation and class weights are fitted inside training partitions. The test set is never used for tuning.
  • 0 development recordings have at least one missing voice-quality measurement. Missing values use training-only medians and indicators.
  • Only one small, controlled dataset is used. Results do not establish performance on phones, connected speech, unseen sites, or specific disorder types.
  • The reference is a multiclass scoping review, not a model benchmark. This binary project adopts its evaluation recommendations without claiming to reproduce its results.
